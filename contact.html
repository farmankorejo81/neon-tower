Contact and Feedback

Your feedback helps identify confusing controls, browser problems and opportunities to improve the game.

Neon Tower currently provides project feedback through GitHub Issues. This is a public issue tracker, not a private support inbox.

Send feedback

Open the project issue page to report a reproducible bug, ask a project-related question or suggest an improvement.

Open GitHub Issues

What to include in a useful bug report

  1. Device: desktop, phone or tablet, and the operating system if known.
  2. Browser: browser name and version if available.
  3. Steps: the exact actions taken before the problem appeared.
  4. Expected result: what you thought should happen.
  5. Actual result: what happened instead.

Before reporting a problem

  • Refresh the page and try one more round.
  • Check whether your browser is up to date.
  • If touch input is not responding, try tapping inside the game area rather than the surrounding page.
  • Check the How to Play guide for supported controls and game rules.

Privacy and public posts

GitHub Issues may be visible to anyone. Do not include passwords, private messages, phone numbers, home addresses, payment information or other sensitive details. If you attach a screenshot, check it for personal information first.
