Before you post

  • Describe what happened and which browser/device you used.
  • For a game bug, include the steps needed to reproduce it.
  • Do not share passwords, payment details, or other sensitive personal information in a public issue.

GitHub issues are public unless a repository feature specifically says otherwise. Do not use this page for urgent support.
