NEON TOWER

About Neon Tower

Neon Tower is a small, free stacking game designed for quick play in a web browser. The goal is simple: time each drop, line up the moving block with the tower, and build the tallest stack you can.

How it works

Start a round and drop each moving block by tapping or clicking the play area, or by pressing Space or Enter on a keyboard. Accurate placements help you keep your tower wide and build combos. If a block misses the tower, the round ends and you can start again.

Designed for simple play

The game features a neon-inspired visual style, optional sound, a score counter, and a best score stored in your browser when local storage is available. It does not require an account or a download.

Feedback

If you find a problem or have a suggestion, you can open an issue on the Neon Tower GitHub repository. Please do not post passwords or other private information in a public issue.
